## 🛠️ Featured Projects

### 🌱 SMAI — Intelligent Agricultural Monitoring System
> IoT + AI system for real-time crop monitoring and automated irrigation decisions

- **ESP32** collects soil moisture and temperature sensor data
- **Firebase Realtime Database** stores and syncs data in real time
- **LLM via OpenRouter API** generates intelligent irrigation recommendations (Generative AI)
- **Streamlit + Plotly** dashboard with live updates and push notifications via ntfy.sh
- Full pipeline from raw sensor signal to automated decision — no manual intervention

**Stack:** `Python` `Firebase` `LLM / OpenRouter` `Streamlit` `Plotly` `Pandas` `IoT` `ESP32`

🔗 [View Repository](https://github.com/GuillerZ34/SMAI-Project)

### 🎬 MovieLens Data Pipeline & D3.js Visualization
> End-to-end data engineering pipeline on the MovieLens ratings dataset

- Ingests and cleans raw MovieLens data using **Pandas** and **NumPy**
- Transforms and loads into a structured **SQLite** database via a custom ETL pipeline
- Renders interactive **D3.js** visualizations of rating distributions and top-rated content
- Demonstrates the full data lifecycle: ingest → wrangle → store → visualize

**Stack:** `Python` `Pandas` `NumPy` `SQLite` `SQL` `ETL` `D3.js` `Data Visualization`

🔗 [View Repository](https://github.com/GuillerZ34/Movies-Project)
